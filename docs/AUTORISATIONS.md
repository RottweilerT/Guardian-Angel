# Autorisations à demander

Aucun des contenus ci-dessous n'est intégré. Chaque demande doit décrire le projet (gratuit, sans publicité, code ouvert), l'usage précis (affichage dans une application web et mobile, hors ligne), le volume et le territoire. Conserver la réponse écrite et la référencer dans le registre (`preuve`).
